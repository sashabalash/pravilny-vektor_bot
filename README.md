# 🤖 Бот онлайн-школы «Правильный Вектор»

Telegram-бот на **Python 3.10+ / aiogram 3.x**: запись на пробный урок, напоминания о занятиях и оплате,
приём домашних заданий, еженедельные отчёты родителям, FAQ и админ-панель преподавателя.

## Возможности

| Раздел | Что делает |
|---|---|
| Регистрация и запись | Единая воронка: роль → предмет → цель → формат → контакты. Ссылка с сайта пропускает выбор и просит подтвердить запись |
| Пробный урок | Заявка (с предметом, целью и форматом) уходит администраторам с кнопкой «Обработана» |
| Роли | Администратор (ID из `.env`), преподаватель (добавляет админ), ученик, родитель |
| Расписание | `/schedule`; напоминания за 1 час и за 10 минут (APScheduler) |
| Домашние задания | Админ выдаёт ДЗ → ученик сдаёт фото/текст/файлы → админ ставит «Отлично / Принято / На доработку» |
| Оплата | `/balance`; напоминание за 3 дня до конца пакета; ссылка на оплату — заглушка |
| Отчёты | Каждый понедельник в 10:00 родителям; по запросу — `/report` |
| FAQ | Вопросы из БД, админ добавляет/удаляет |
| Материалы | Чек-листы и файлы (PDF, картинки): кнопка «📎 Материалы» и ссылки из канала `t.me/<бот>?start=mat_<id>` |
| Админ-панель | `/admin`: ученики, расписание, ДЗ, оплата, заявки, рассылка, статистика, FAQ |

## Установка

```bash
# 1. Перейдите в папку проекта
cd pravilny-vektor-bot

# 2. Создайте виртуальное окружение
python3 -m venv venv
source venv/bin/activate          # Windows: venv\Scripts\activate

# 3. Установите зависимости
pip install -r requirements.txt
```

## Настройка

1. Создайте бота в [@BotFather](https://t.me/BotFather) и скопируйте токен.
2. Узнайте свой Telegram ID, например у [@userinfobot](https://t.me/userinfobot).
3. Скопируйте файл настроек и заполните его:

```bash
cp .env.example .env
```

```env
BOT_TOKEN=123456789:AAExampleTokenFromBotFather
ADMIN_IDS=123456789,987654321
TIMEZONE=Europe/Minsk
DB_PATH=pravilny_vektor.db
PAYMENT_URL=https://pravilny-vektor.by
```

## Запуск

```bash
python bot.py
```

База `pravilny_vektor.db` создаётся автоматически при первом запуске, логи пишутся в `bot.log`.
Остановка — `Ctrl+C`.

### Запуск на сервере (systemd)

```ini
# /etc/systemd/system/pravilny-vektor-bot.service
[Unit]
Description=Pravilny Vektor Telegram Bot
After=network.target

[Service]
WorkingDirectory=/opt/pravilny-vektor-bot
ExecStart=/opt/pravilny-vektor-bot/venv/bin/python bot.py
Restart=always
User=botuser

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl enable --now pravilny-vektor-bot
```

## Как добавить нового администратора

1. Попросите человека написать боту `/start` или узнать ID у [@userinfobot](https://t.me/userinfobot).
2. Откройте `.env` и добавьте ID в `ADMIN_IDS` через запятую:
   `ADMIN_IDS=123456789,555666777`
3. Перезапустите бота (`Ctrl+C` и `python bot.py`, либо `sudo systemctl restart pravilny-vektor-bot`).
4. Новый администратор отправляет `/admin` — откроется панель. Уведомления (заявки, сдачи ДЗ, новые регистрации) придут всем администраторам.

Удалить администратора — убрать его ID из `ADMIN_IDS` и перезапустить бота.

## Как пользоваться (коротко)

1. **Ученик регистрируется** через `/start`. **Родитель** указывает имя ребёнка — оно должно совпадать с именем в регистрации ученика, так бот связывает аккаунты.
2. **Админ принимает оплату**: `/admin` → «Оплата» → ученик → число занятий, сумма, срок пакета. Баланс пополняется, срок пакета запоминается.
3. **Админ добавляет занятие**: «Расписание» → «Добавить занятие» (дата `ДД.ММ.ГГГГ`, время `ЧЧ:ММ`, ссылка). Ученик и родитель получают уведомление, затем напоминания.
4. **После занятия** админ отмечает его: «Расписание» → «Ближайшие занятия» → «Проведено» (списывает 1 занятие с баланса) или «Пропущено».
5. **ДЗ**: «Домашние задания» → «Выдать ДЗ». Работы учеников приходят админу с кнопками оценки; результат уходит ученику.
6. **Материалы**: `/admin` → «Материалы» → «Добавить материал»: название, затем PDF или картинка (подпись станет описанием). Бот выдаст ссылку для поста в канале; открыв её, человек сразу получает файл, даже без регистрации.
7. **Комментарий в еженедельный отчёт**: карточка ученика → «Комментарий к отчёту» (после отправки очищается).

## Роли и панели

| Роль | Как попадает | Что видит |
|---|---|---|
| **Администратор** | Telegram ID в `ADMIN_IDS` (`.env`) | `/admin`: ученики, **преподаватели** (добавить/удалить по Telegram ID), расписание, ДЗ, оплата, заявки, **общая статистика школы**, **статистика по любому ученику**, рассылка, FAQ, материалы |
| **Преподаватель** | Админ добавляет его в `/admin` → «Преподаватели» | `/teacher`: **«Мои ученики»**, **«Моя статистика»** (только его ученики: сколько учеников, проведено занятий, сколько оплатили), **«Статистика по ученику»** (только свои), «Мои занятия» (отметка проведено/пропущено) |
| Ученик, родитель | Регистрируются через воронку записи | Расписание, ДЗ, баланс, отчёты, материалы, FAQ |

**Привязка ученика к преподавателю:** `/admin` → «Ученики» → карточка ученика → «👨‍🏫 Преподаватель». После этого ученик появляется в панели преподавателя, а его будущие занятия закрепляются за ним. Если у преподавателя пока нет учеников, бот пишет «У вас пока нет учеников».

## Ссылки с сайта (Deep Link)

Кнопки на сайте ведут на `https://t.me/pravilny_vektor_bot?start=<формат>_<предмет>_<цель>`:

| Часть | Значения |
|---|---|
| формат | `ind` — индивидуально, `grp` — мини-группа |
| предмет | `mat` — математика, `eng` — английский, `other` — другой |
| цель | `base` — подтянуть базу, `ct` — ЦТ/ЦЭ, `hard` — сложные темы |

Пример: `?start=ind_mat_ct`. Бот расшифрует код, покажет заявку и попросит подтвердить. Новому пользователю дополнительно нужно выбрать роль и оставить контакты. Ссылки вида `?start=mat_<число>` по-прежнему выдают материал из раздела «Материалы».

## Миграция со старой базы

Бот версии 2 работает с новой структурой базы (`school_new.db`). Если он запущен на старой базе, то остановится с подсказкой выполнить миграцию. Старая база при этом **не изменяется**.

```bash
source venv/bin/activate
python migration.py --old pravilny_vektor.db --new school_new.db
```

Скрипт переносит пользователей, заявки, занятия, ДЗ и работы, оплаты, отчёты, FAQ и материалы, назначает роль `admin` для ID из `.env` (создаёт запись, если её нет) и печатает отчёт. После успеха:

1. В `.env` укажите `DB_PATH=school_new.db`.
2. Запустите бота: `python bot.py`.
3. Привяжите учеников к преподавателям в админ-панели.

Если `school_new.db` уже существует, скрипт остановится; для перезаписи добавьте `--force`.

## Важные замечания

- **Оценки.** «Отлично» = 10, «Принято» = 8 баллов (шкала в `config.py`, `HW_SCORES`). «На доработку» балла не получает — оценка появится после пересдачи.
- **Оплата.** Ссылка `PAYMENT_URL` — заглушка. Для подключения платёжной системы замените значение в `.env` (или доработайте `handlers/payment.py`).
- **Состояния диалогов** хранятся в памяти (`MemoryStorage`): при перезапуске незавершённые диалоги сбрасываются. Данные в БД сохраняются. Для продакшена можно подключить `RedisStorage`.
- **Напоминания** не дублируются после перезапуска: флаги отправки хранятся в БД.
- **PostgreSQL.** Весь SQL собран в `database.py`; для перехода замените реализацию методов (например, на `asyncpg`), хендлеры менять не нужно.
- **Права.** Админ-хендлеры доступны только Telegram ID из `ADMIN_IDS`; заблокированные пользователи получают отказ на любое действие.
- В списках админки показывается до 50 пользователей — для большой базы потребуется пагинация.
